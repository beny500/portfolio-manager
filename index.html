Préférences & sécurité

Paramètres

Gère les sauvegardes, les imports et l'installation de Portfolio Manager.

Sauvegarde & restauration

Exporte tes positions, l'historique de valorisation et tes paiements de dividendes/coupons dans un fichier JSON.

Importer des positions

Importe les fichiers CSV de Caisse d'Épargne, DEGIRO ou Revolut. Vérifie toujours l'aperçu avant de remplacer un compte.

Configuration privée des cotations

Importe le fichier privé de correspondance des tickers. Il reste dans le stockage de ce navigateur et n’est jamais envoyé sur GitHub.

Configuration non importée.

Réinitialisation

Supprime les positions après confirmation. L'historique des dividendes et coupons reste conservé. Une sauvegarde est téléchargée avant l'opération.

Installer sur iPhone

Application prête à être configurée pour une installation PWA. L'installation nécessite une adresse web sécurisée (HTTPS).

  1. Publie le dossier de l'application sur un hébergement HTTPS.
  2. Ouvre l'adresse du site dans Safari sur ton iPhone.
  3. Touche Partager, puis Sur l'écran d'accueil.
  4. Active Ouvrir comme app web si cette option est proposée, puis ajoute l'app.
Vérification du service worker après publication HTTPS…

Stockage des données

Les positions et les revenus sont stockés localement dans le navigateur. L'application n'est pas encore synchronisée entre ton ordinateur et ton iPhone. Effectue régulièrement une sauvegarde JSON et conserve-la dans un emplacement sûr.

Ajouter une position

Renseignez les informations du titre. Tous les prix sont saisis en euros. Pour les nouveaux paiements datés, utilisez la rubrique Dividendes & coupons.

Enregistrer un revenu encaissé

Uniquement un paiement effectivement reçu. Les montants sont saisis en euros.

Renseigne au moins le montant brut ou le montant net. Si le net est disponible, il sera retenu pour le total encaissé ; sinon le brut sera utilisé. Aucun paiement futur ne peut être enregistré.

Importer des positions

Importez un fichier CSV pour un compte à la fois.

Séparateur point-virgule ou virgule accepté.
Vérifiez les correspondances avant validation. Les colonnes Nom, Quantité et Dernier cours sont obligatoires. Le PRU peut rester vide.
